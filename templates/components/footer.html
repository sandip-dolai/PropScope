PS PropScope Engine

Enterprise geospatial property platform performing geodetic distance calculations, PostGIS spatial indexing, and multi-tier infrastructure connectivity analysis.

Geospatial Architecture
  • PostgreSQL 16 + PostGIS 3.4
  • WGS-84 (SRID 4326) Geodetic Coordinates
  • GiST 2D Spatial Indexing
  • KNN Amenity Proximity Engine
Application Stack
  • Django 5.1 & Django REST Framework
  • Celery Asynchronous Task Workers
  • Redis 7 In-Memory State Cache
  • Leaflet.js + CartoDB Vector Maps
Developer Interfaces
  • OpenAPI 3.0 Interactive Swagger
  • ReDoc Reference Documentation
  • Properties REST API
  • Sub-Market Polygon API
